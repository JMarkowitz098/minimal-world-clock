# Minimal World Clock

## Features
- Window with a clock that can be set to different time zones
- Window where you can easily and intuitively compare two different time zones
- Widget where you can display the time for a specific time zone on the mac desktop

## Requirements
- Ai created and designed, so optimized for that approach
- Use TDD
- Use a road map
- Readme updated for humans to work with the repo. Should include local testing and deploying instructions
- Will eventually be launched on the apple app store
- Should use github
- Can reference ~/Projects/pomodoro_timer for previous approach
- Made for accessibility, e.x. screen readers, color blindness, and other things
- Lightweight and minimal. 
- Nonobtrusive popup to ask users to buy the app, similar to the pomodor app
