# M4: Compare window

A second window (Window menu, ⌘2) comparing two zones. Shows both times side by side with the difference and day relation from M2. A **time scrubber** (slider or 24-hour strip) sets a time in zone A and shows the matching time in zone B, with a "Now" button to return to live. Swap button exchanges the zones. Both zones persist. As built: a slider over zone A's day in quarter hours; swap keeps the instant; see design_doc.md → Compare window.
- Tests: view model: live mode tracks now; scrubbing sets the instant from zone A's wall time; B updates; swap; Now resets; day-relation labels; persistence. As built: `liveModeTracksNow`, `displayStringsForBothZones`, `scrubbingSetsTheInstantFromZoneAWallTime`, `zoneBFollowsTheScrubbedTime`, `scrubberShowsZoneATimeWhenLive`, `scrubbedTimeStaysPutAsTimePasses`, `scrubIntoADSTGapMovesForward`, `nowReturnsToLive`, `swapExchangesZones`, `swapKeepsTheScrubbedInstant`, `changingZoneAKeepsTheScrubbedWallTime`, `changingZoneBKeepsTheInstant`, `dayRelationLabels`, `dayRelationTwoDaysApart`, `sameZoneReadsSameTime`, `stopCancelsTheCompareTicker`, `compareZonesPersistAcrossLaunches`, `swapPersists`, `missingOrCorruptCompareZonesUseDefaults`; store: `compareZonesRoundTripThroughUserDefaults`, `compareZonesAreSavedIndependently`.
- Done when: tests pass; scheduling a call (e.g. "3 pm in New York is what in Tokyo?") takes one drag.

**Calls made without asking** (the user can revisit them): Compare defaults to the Mac's zone and UTC; the scrubber covers zone A's current day only; swapping while scrubbed keeps the instant.
